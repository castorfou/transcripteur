# transcripteur

Outils de transcription multi langue avec differents plugins : transcription brute, detection d'interlocuteurs, creation de sous-titres, ... et peut se connecter à différentes entrées ou sorties audio

## pyfoundry-template

Ce projet a été instancié depuis un template.

Toutes les infos sur ce template et la façon de l'utiliser sont dans sa [documentation](https://castorfou.github.io/PyFoundry/).
